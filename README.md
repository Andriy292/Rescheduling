# Xcedy Launcher

Лаунчер для Minecraft Bedrock на Android (Kotlin + Jetpack Compose).

## Сборка через GitHub
1. Создай репозиторий на GitHub и загрузи в него все файлы этой папки.
2. Открой вкладку **Actions** -> **Build APK** -> дождись зелёной галочки.
3. Внутри запуска, в разделе **Artifacts**, скачай `XcedyLauncher-debug` (внутри APK).

## Шаги
1. Скелет и облачная сборка (готово)
2. Главный экран (заготовка есть)
3. Импорт и привязка APK
4. Аккаунты
5. Моды, ресурспаки, сборки
6. Оверлей Xcedy
